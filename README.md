# Finance Engine

Forecasting & control platform — sales/cash forecasting, budget planning, cost controlling, variance analysis, profitability, and KPI reporting, built to scale from a single company to a multi-entity group.

See [ROADMAP.md](./ROADMAP.md) for the phased plan and architecture. Phase 1 build hasn't started yet — repo is scaffolded, module code comes next once the open decisions in ROADMAP.md §7 are settled.

## Layout

- `backend/` — Python/FastAPI service, forecast engine, Postgres schema
- `frontend/` — React + TypeScript UI
- `docs/` — supporting design docs
